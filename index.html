What is Application Security?

Application Security (AppSec) focuses on finding and fixing security weaknesses inside the software itself — the code, the logic, and how an app handles data — rather than just the network it runs on.

What I'm currently learning

  • JavaScript and web architecture, so I understand how the applications I'll be securing are actually built
  • HTTP and how browsers and servers communicate
  • Social engineering fundamentals and identity management
  • Core web security concepts that connect directly to my web development learning

Why I'm learning web development first
